# Security and privacy policy

## What counts

This tool handles course files and, if misused, could expose them. Report any of:

- A course file (slides, notes, exam material) or patient information committed to
  this repository, a fork, a PR, an issue, or a release.
- A secret (API key, token) committed anywhere.
- A script behavior that sends data somewhere the docs do not describe.
- A vulnerability in the scripts.

Follow your institution's AI policy; never include course content or patient information in a report.

## How to report

**Do not open a public issue or PR.** Use a private security advisory:
Security tab > "Report a vulnerability" on this repository.

Include where the material is (file path, commit SHA, PR number). Do not paste the
material itself into the report.

## What to expect

We aim to acknowledge within 3 days, and to remove committed private material (including
rewriting history where needed) as soon as we can confirm it. If you committed course
files by accident, tell us right away: you may also need to tell your school.

## Supported versions

Only the latest release on `main` is supported.
